CRFFN Licensing Dashboard

Manage applications from submission to licence issuance.

Applications progress through three workflow stages. Review each stage before the application moves to the next one.

Stage 1

Application Review

Review applicant information and supporting documents.

  • Review submitted information
  • Review uploaded documents
  • Request corrections where required
  • Approve applications for payment
Stage 2

Payment Verification

Verify applicant payment submissions.

  • Review payment receipt
  • Confirm payment
  • Reject invalid payment submissions

Confirmed payments move automatically to licence creation.

Stage 3

Licence Creation

Generate and issue the final licence.

  • Generate, view, or download the draft
  • Upload the stamped licence
  • Send the licence to the applicant

Application Search

Find an application by ID or applicant email

The search identifies the application’s current workflow stage and opens the correct detail page.

Search only locates the application. Full information, documents, payment details, and licence details load only after opening its detail page.
